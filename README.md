# Z761293629/homebrew-tap

Install [crablink](https://github.com/Z761293629/crablink) with `brew install Z761293629/tap/crablink` (macOS on Apple silicon, Linux x86_64/arm64).

`Formula/crablink.rb` is generated by [`scripts/homebrew-formula.sh`](https://github.com/Z761293629/crablink/blob/main/scripts/homebrew-formula.sh) in crablink on every stable release. Don't edit it here; change the script instead.
